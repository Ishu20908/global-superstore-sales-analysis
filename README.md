# Global Superstore Sales & Profitability Analysis

## Project Overview

This project analyzes the Global Superstore dataset using Python to identify sales trends, profitability patterns, regional performance, category performance, and loss-making products.

The project includes data preprocessing, exploratory data analysis, visualization, and filter-based analysis.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Project Workflow

1. Data Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Data Visualization
5. Category Analysis
6. Regional Analysis
7. Year-wise Sales and Profit Analysis
8. Insights and Filters

## Key Insights

- Office Supplies generated the highest sales and total profit.
- 2014 recorded the highest sales and profit.
- Southeast Asia recorded an overall loss.
- Sales and order count increased from 2011 to 2014.
- Furniture generated strong sales but had comparatively lower profitability.
- Some products generated negative profit and require further analysis.
- Discount levels may influence product profitability.
